# ChessBot
26 판도라큐브 유니티 ML-Agent 강화학습 스터디 과제

## 개요
Unity ML-Agent를 이용해 Self-Play로 체스 대결을 할 수 있는 Agent를 설계한다.<br>
학습 방법은 sac를 사용하며, Curriculum Learning을 통해 기본적인 체스의 룰을 이해하고, 전략을 사용하며 궁극적으로 포지션 평가까지 가능하도록 하는 것이 목적이다.

## 요구사항
1. 기본적인 체스 룰을 따르는 체스 게임이 가능해야 한다.</br>
   1-1. 플레이어는 흑과 백으로 나누며, 각 플레이어는 8개의 폰과 룩,비숍,나이트를 2개씩, 킹과 퀸을 가진다.</br>
   1-2. 말들의 배치는 체스의 기본 배치를 따르며, 각 말들은 체스의 기본 행마법을 따른다.</br>
   1-3. 선공은 백이 하고, 한 턴에 하나의 말을 움직일 수 있다.<br>
2. 체스 게임을 하는 Agent를 구성해야 한다.<br>
   2-1. 관측값은 체스 말들의 위치를 갖는다.<br>
   2-2. 보상은 기본적으로 말을 먹었을 때 부여하며, 먹은 말과 먹힌 말의 점수 차이를 고려해 보상을 부여한다.<br>
