# ChessBot

2026 판도라큐브 Unity ML-Agents 강화학습 스터디 과제

## 개요

Unity ML-Agents를 이용해 Self-Play(자가 대전)로 체스를 학습하는 Agent를 설계한다. 체스 규칙에 따라 대국을 진행하는 환경을 구현하고, 두 Agent가 반복적으로 대국하며 학습할 수 있도록 하는 것이 목표다.

학습 방법은 SAC를 사용하며, Curriculum Learning을 통해 기본 체스 규칙 이해에서 전략 활용, 궁극적으로 포지션 평가까지 발전시키는 것을 목표로 한다.

## 단계별 구현 목표

### 1단계: 체스 룰 이해

- Agent가 말의 행마법을 이해하고 정상적인 턴제 체스 게임을 진행할 수 있도록 한다.
- 이후 단계의 세부 과제와 전환 기준은 학습 설계 단계에서 구체화한다.

## 요구사항

### 체스 게임

- 8×8 보드에서 백과 흑이 대국한다.
- 각 진영은 폰 8개, 룩·비숍·나이트 각 2개, 킹·퀸 각 1개로 시작한다.
- 말의 초기 배치와 이동은 기본 체스 규칙을 따른다.
- 백이 먼저 시작하며, 이후 두 진영이 번갈아 한 수씩 둔다.
- 현재 진영의 합법적인 수만 허용하며, 자신의 킹을 체크 상태에 두는 수는 금지한다.
- 체크와 체크메이트를 판정하고, 대국 종료 시 결과를 기록한다.
- 대국이 종료되면 보드와 턴 상태를 초기화해 다음 대국을 시작할 수 있어야 한다.

- 캐슬링, 앙파상, 폰의 승격을 포함한 표준 체스 규칙 전체를 구현한다.
- 스테일메이트, 체크메이트가 불가능한 포지션, 반복 및 수순 제한에 따른 무승부를 처리한다. 선언이 필요한 무승부와 자동 무승부를 구분한다.

캐슬링처럼 여러 말의 위치가 함께 바뀌는 특수 수를 고려해 턴 단위는 한 수로 정의한다.

### 대전 방식

- Agent 간 Self-Play: 두 Agent가 대국하며 학습하고, 학습된 정책을 평가한다.
- 사람 대 Agent: 사람이 보드에서 수를 입력하고 학습된 Agent와 대국한다. 사람과 Agent 모두 동일한 규칙 판정을 사용한다.

### 강화학습 Agent

- Agent의 관측값은 체스 말들의 위치를 포함하며, 자신의 진영과 차례를 파악할 수 있어야 한다.
- 자신의 차례에 합법적인 수를 선택하고 게임 환경에 적용할 수 있어야 한다.
- 합법 수 판정은 게임 규칙 로직을 공통으로 사용한다.
- 한 대국을 하나의 학습 에피소드로 다루고, 종료 시 두 Agent의 상태를 함께 초기화한다.
- 말을 포획했을 때 보상을 부여하며, 먹은 말과 먹힌 말의 점수 차이를 고려한다. 기물 점수와 보상 계산식은 학습 설계 단계에서 구체화한다.
- 승리·패배·무승부에 대한 보상 기준을 정의한다. 종료 보상과 포획 보상의 수치는 학습 설계 단계에서 결정한다.
- Self-Play 학습을 실행하고, 학습 결과를 저장해 평가할 수 있어야 한다.

## 검증 계획

현재 별도의 체스 테스트는 없다. 구현 시 다음 항목을 확인한다.

- 초기 배치, 진영별 턴 전환 및 말별 이동·포획이 요구사항과 일치하는지
- 보드 밖 이동, 아군 말 포획, 자신의 킹을 체크에 노출하는 수가 차단되는지
- 체크·체크메이트와 표준 특수 규칙이 올바르게 판정되는지
- 대국 종료와 초기화 후 이전 대국의 상태가 남지 않는지
- Agent가 합법적인 행동을 선택하고 보상과 에피소드 종료를 일관되게 받는지
- 평가 시 상대 정책, 대국 수, 백·흑 배정, 승·무·패 및 사용 모델을 함께 기록하는지

## 미정 사항
- 학습 설계: 관측 표현, 행동 표현, 기물 점수와 보상 수치, Curriculum 단계 및 학습 예산
- 완료 기준: 평가 상대, 평가 대국 수 및 목표 성능

범위가 확정되면 해당 내용을 요구사항과 구현 계획에 반영한다.
