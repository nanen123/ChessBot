# 0-A 포획 단계 일반화 격차 진단

## 결론

고정된 학습 표본만 쉬웠던 현상으로 설명되지 않는다. 전체 학습 위치에서도 98.73%를 맞히지만 별도 평가 위치는 51.56%이며, 같은 학습 위치를 좌우 반전하면 44.92%로 떨어진다. **특정 배치·좌표에 대한 의존성과 일반화 부족**이 확인된다. 과적합 해석을 강하게 지지하지만 신경망 구조나 최적화 설정 중 어느 하나가 단독 원인인지는 이 실험만으로 확정하지 않는다.

실행 중 학습이나 학습 자료는 변경하지 않고 저장된 ONNX를 복사해 CPU 단일 스레드로 검사했다. 적용 범위는 0단계 난이도 0(0-A)이다.

## 고정 모델과 자료

- 최고 평가 모델: 400,237 step, SHA256 `4c2140d3ba499a32639121e134d6050b216a9d07c391919e551b2519fd99aa8c`.
- 검사 시점 최신 평가 모델: 500,253 step, SHA256 `5e42cea7edfbd83207843aae2ec5015a1a8efac1a3e25bd81466a8eac74848e0`.
- 자료 SHA256: `c93610fefdee7df603290646cfdc196de69ee058d51c212b2d9e5b1cdd8c1912`.
- 원본 평가 로그의 모델 해시와 일치함을 확인했다. 모델은 `output/training-validation/capture-gap-audit/`에 복사해 보존했다.
- 학습 위치 1,024개와 평가 위치 64개 각각에 기존 색 반전을 적용했다. 2,048/128회는 독립 위치 수가 아니라 양색 검사 횟수다.

| 모델 | 학습 전체 | 별도 평가 |
| --- | ---: | ---: |
| 400,237 step | 2,022/2,048 = 98.73% | 69/128 = 53.91% |
| 500,253 step | 2,022/2,048 = 98.73% | 66/128 = 51.56% |

기존 Training Success 100%는 고정된 64개에서의 결과다. 전체로 넓히면 98.73%로 조금 낮아지지만, 약 47.17%포인트의 격차는 여전히 남는다.

## 실패 유형

최신 모델의 평가 실패 62회 중 **61회는 비포획 수**, 1회는 불리한 포획이었다. 이 단계에서는 유리한 포획이 있는 상황에서 한 수로 과제를 해결해야 하므로 비포획 수는 실패다. 장기 대국의 최선 수를 판정한 결과는 아니다.

아래는 유리한 포획을 할 수 있는 기물 종류가 하나뿐인 묶음이다. 잡히는 기물의 종류가 아니다. 여러 기물 종류로 해결 가능한 위치는 별도 조합 묶음으로 집계했다.

| 포획하는 기물 | 학습 전체 | 평가 |
| --- | ---: | ---: |
| 킹 | 1,060/1,062 (99.8%) | 44/62 (71.0%) |
| 폰 | 128/128 (100%) | 8/10 (80.0%) |
| 룩 | 318/322 (98.8%) | 7/28 (25.0%) |
| 퀸 | 276/290 (95.2%) | 2/14 (14.3%) |
| 나이트 | 72/72 (100%) | 0/4 |
| 비숍 | 60/60 (100%) | 0/2 |

나이트·비숍은 평가 표본이 매우 작으므로 일반적인 기물별 실력을 단정하지 않는다. 룩·퀸 포획의 일반화 실패가 눈에 띈다. 평가 백 35/64, 흑 31/64로 양쪽 모두 낮아서 한쪽 색만의 문제로 설명되지 않는다.

학습·평가에 공통으로 있는 포획 기물 유형의 비율을 학습 쪽 비율에 맞춰 재가중해도 평가 성공률은 약 50.30%다. 이 비교가 포함하는 학습 표본은 1,984/2,048회다. 기물 종류 구성 차이만으로 큰 격차가 설명되지는 않는다. 선택지 수 등 다른 난이도 요인의 영향까지 배제한 것은 아니다.

## 좌우 반전 대조 실험

- 최신 모델의 학습 위치를 좌우로 뒤집었다. 캐슬링 권리가 있는 위치는 제외하도록 했고, 결과적으로 2,048회 모두 검사했다.
- 각 변환 배치의 합법성·비종료 상태 및 유리한 포획 집합이 정확히 좌우 대응하는지 확인했다.
- 변환 배치가 기존 모든 단계의 학습 시작 배치와 중복되지 않는지도 색 반전까지 묶어 확인했다.
- 비교 양쪽 모두 이전 반복 이력을 제거했다. 원본의 이력 유무로 선택 행동이 달라진 경우는 0회여서, 아래 차이를 이력 제거로 설명할 수 없다.

| 같은 위치의 표현 | 성공 |
| --- | ---: |
| 원본 | 2,022/2,048 (98.73%) |
| 좌우 반전 | 920/2,048 (44.92%) |

포획 관계가 같은데도 좌표가 바뀌면 크게 실패한다. 현재 관측은 절대 좌표의 기물 배열이고 행동도 절대 출발·도착 칸으로 표현한다. 이 구조는 좌우 대칭이나 기물 이동 관계를 자동으로 공유하도록 강제하지 않는다. 다만 구조 변경으로 개선되는지까지 실험하지 않았으므로 구조만을 확정 원인으로 지목하지 않는다. 좌우 반전 문제는 통제된 변환 문제이며 별도 실제 경기에서 새로 뽑은 독립 검증 세트는 아니다.

## 최근 하락과 구현 교차 검증

- 최고점부터 최신까지 평가 66회는 계속 성공, 59회는 계속 실패, 3회는 성공→실패, 실패→성공은 0회였다. 학습 전체의 성공/실패 집합은 같았다.
- 즉 최근 추가 학습으로 고정 평가에서 새로 해결한 문제가 없었다. 3회 하락 자체의 크기는 작지만, 큰 일반화 격차가 유지되는 점이 핵심이다.
- 최신 평가 128회의 선택 수와 모든 유리한 포획 후보를 합친 204개 판정을 현재 프로젝트의 `ChessTacticalAssessment` C# 소스로 독립 컴파일해 비교했다. 모두 합법 수이며 성공 판정은 Python과 일치했다.
- 이전 검증의 Unity/Python 관측·행동 마스크 98개 일치 결과도 참고했다. 이번 조사로 모든 가능한 런타임 결함을 배제한 것은 아니지만 검사한 포획 판정에서 불일치는 없었다.

## 다음 수정 우선순위

1. 0단계에서 합법적인 좌우 반전 등의 배치 변형을 학습에 포함해, 같은 포획 관계를 여러 좌표에서 경험하게 한다. 현재 고정 평가 및 진단 변환 배치는 학습용 증강과의 중복을 다시 점검하거나 별도 미사용 검증 세트를 확보해야 한다.
2. 룩·퀸 등 부족한 유형과 다양한 포획 거리·방향을 보강한다. 위치 개수만 늘리지 말고 유형별 비율을 관리한다.
3. 원래 학습/평가, 대칭 대조, 새로운 미사용 경기 표본에서 함께 개선되는지 비교한다. 평가 문제를 그대로 학습에 넣거나 승급 기준만 낮추지 않는다.
4. 위 실험 이후에도 개선이 없으면 좌표·기물 관계를 공유하기 쉬운 관측/정책 구조를 검토한다. 구조 변경은 모델 호환성과 재학습 비용을 별도로 검토한다.

## 재현 및 산출물

프로젝트 루트에서:

```powershell
.venv-training/Scripts/python.exe Tools/DiagnoseCaptureGap.py --run results/curriculum_3
.venv-training/Scripts/python.exe Tools/DiagnoseCaptureSymmetry.py
```

최고점 모델은 현재 보존된 ONNX와 평가 기록을 기준으로 선택한다. 체크포인트 보존 정책에 의해 원본이 삭제되면 같은 모델을 자동으로 다시 선택할 수 없으므로 이번 복사본의 해시를 기준으로 비교한다.

- `output/training-validation/capture-gap-audit/summary.json`: 전체·기물·색별 집계와 모델 비교.
- `best-cases.json`, `latest-cases.json`: 배치별 원본 경기, FEN, 선택 수, 정답 후보와 성공 여부.
- `symmetry.json`: 좌우 반전 대조 결과.
- `tactics.tsv`, `CaptureAudit.cs`: 204개 C#/Python 교차 판정 입력과 검사 코드.
