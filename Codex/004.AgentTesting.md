# 학습 모델 대국 테스트

`Assets/Scenes/AgentTest.unity`를 열고 Play를 누른다. 메뉴 `ChessBot > Testing > Open Agent Test`로도 열 수 있다. Python 학습기를 실행할 필요가 없다.

기본 모드는 **Agent Vs Agent**다. 백과 흑이 각자 지정된 ONNX를 추론 전용으로 사용하며, 보드에 수와 결과가 표시된다. 초기 연결 모델 `Assets/Models/ChessV1_Test.onnx`는 `results/first/ChessV1.onnx`의 사본이다. 학습이 진행되어 원본이 갱신되어도 사본은 자동으로 변경되지 않는다. 이 모델의 실력을 보증하는 평가 결과는 아니다.

## Inspector 설정

씬의 `Chess Model Evaluation` 오브젝트에서 설정한다. 모드와 모델은 Play 시작 전에 변경한다.

| 항목 | 의미 |
| --- | --- |
| Mode | Agent Vs Agent: 관전 / Human Vs Agent: 사람 대 모델 |
| White Model, Black Model | 백·흑 ONNX. 동일 모델 또는 서로 다른 체크포인트를 지정할 수 있다. |
| Human Color | 사람 대 모델일 때 사람의 색상. 해당 색상 모델은 사용하지 않는다. |
| Seconds Per Move | Agent 수 사이의 실제 시간 간격. 기본 0.5초 |
| Maximum Plies | 테스트 반수 제한. 도달 시 승패 판정 없이 정지한다. 학습 당시 값과 맞추면 진행률 관측도 일치한다. |
| Deterministic | 켜면 모델의 결정적 출력을 사용한다. 끄면 정책에서 수를 샘플링한다. |

화면의 Pause / Resume으로 일시정지·재개, New game으로 초기 배치 재시작, Flip board로 보드 방향을 전환한다. 일시정지 상태에서 새 대국을 시작하면 정지 상태를 유지한다. 관전 모드에서는 기물 이동·기권·무승부 선언을 사람이 대신할 수 없다. 사람 모드에서는 사람 차례에만 입력할 수 있다.

새 ONNX를 테스트하려면 `Assets/Models/`에 복사하고 Unity의 임포트가 완료된 뒤 White Model 또는 Black Model에 드래그한다. 두 모델 모두 ChessV1 관측 844개·행동 마스크 8577개 및 같은 인코딩 의미를 사용해야 한다. 코드에서 입력 크기와 출력 이름을 검사하지만, 같은 크기의 다른 의미를 가진 모델까지 자동으로 식별할 수는 없다. 모델이 없거나 기본 형식이 맞지 않으면 설정 오류를 표시하고 대국을 멈춘다. 무작위 정책으로 대체하지 않는다.

이 씬은 수동 관전·대국 확인용이다. 학습 보상을 부여하거나 가중치를 갱신하지 않는다. 다수 대국의 자동 승률 집계 및 모델 순위 평가는 포함하지 않는다. 모델을 비교할 때는 백·흑 모델을 바꿔서도 확인해야 한다.

## 검증

2026-09-28: 격리된 Unity 6000.3.10f1 Editor에서 PlayMode 8/8 통과. 실제 ONNX 두 모델의 교대 대국, 일시정지·새 대국·재개, 사람 백/흑 차례 처리를 검증했고 기존 로컬 플레이와 학습 Agent 테스트도 함께 통과했다. 별도 컴파일 및 기존 규칙 테스트 45/45도 통과했다. 결과: `output/training-validation/evaluation-playmode.xml`.
